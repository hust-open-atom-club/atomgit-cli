# 如何使用 ag-cli 创建跨仓库 PR (Cross-Repo PR)

*2026-03-20T15:45:37Z by Showboat 0.6.1*
<!-- showboat-id: b030d62e-efd4-4a80-ba65-4606c83a676c -->

在 AtomGit/GitCode 环境下，\n如果你 Fork 了一个上游仓库（如 openeuler/ag-cli 到 mywaaagh_admin/ag-cli），你可能需要从你的 Fork 向前者的 `master` 分支创建一个 Pull Request (合并请求)。\n\n在使用 `ag-cli` 时，要实现这种跨仓库 PR，我们只需要将 `--head` 参数指定为带命名空间的格式，例如 `你的用户名:你的开发分支`（如 `mywaaagh_admin:test-head`）。\n\n新版本的 `ag-cli` 已经支持解析这一参数，并能自动推导成 AtomGit API 需要的 `username/repo:branch` 格式。

举个例子，我们在你的 Fork 仓库 `mywaaagh_admin/ag-cli` 准备了一个名为 `test-head` 的分支，需要将它合并到官方上游仓库 `openeuler/ag-cli` 的 `master` 分支中：

```bash
ag pr create openeuler/ag-cli --title 'Cross Repo PR Demo (Auto-generated by Showboat)' --body 'This is an automated cross-repo PR creation test from my fork.' --base master --head mywaaagh_admin:test-head
```

```output
Created PR #14: 
```

```bash
ag pr close openeuler/ag-cli 14
```

```output
Closed PR #<nil>: 
```

如果你只需要在你的同一个仓库下，从一个开发分支（如 `test-head`）合入到主分支（如 `test-base`），可以直接省略 `owner:` 的前缀，这样系统会判断这是一个内部 PR：

```bash
ag pr create mywaaagh_admin/ag-cli --title 'Internal Repo PR Demo (Auto-generated by Showboat)' --body 'This is an internal PR creation test.' --base test-base --head test-head
```

```output
Created PR #2: 
```

```bash
ag pr close mywaaagh_admin/ag-cli 2
```

```output
Closed PR #<nil>: 
```
