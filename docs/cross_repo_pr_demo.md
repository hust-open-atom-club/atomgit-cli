# 如何使用 ag-cli 创建跨仓库 PR (Cross-Repo PR)

*2026-03-20T15:45:37Z by Showboat 0.6.1*
<!-- showboat-id: b030d62e-efd4-4a80-ba65-4606c83a676c -->

在 AtomGit 环境下，如果你 Fork 了一个上游仓库（如 `hust-open-atom-club/atomgit-cli` 到 `mywaaagh_admin/atomgit-cli`），你可能需要从你的 Fork 向上游的 `main` 分支创建一个 Pull Request（合并请求）。

在使用 `ag` 时，要实现这种跨仓库 PR，只需要将 `--head` 参数指定为带命名空间的格式，例如 `你的用户名:你的开发分支`（如 `mywaaagh_admin:test-head`）。

新版 `ag` 已支持解析这一参数，并能自动推导成 AtomGit API 所需的 `username/repo:branch` 格式。

举个例子，我们在 Fork 仓库 `mywaaagh_admin/atomgit-cli` 准备了一个名为 `test-head` 的分支，需要将它合并到上游仓库 `hust-open-atom-club/atomgit-cli` 的 `main` 分支中：

```bash
ag pr create hust-open-atom-club/atomgit-cli --title 'Cross Repo PR Demo (Auto-generated by Showboat)' --body 'This is an automated cross-repo PR creation test from my fork.' --base main --head mywaaagh_admin:test-head
```

```output
Created PR #14: https://atomgit.com/hust-open-atom-club/atomgit-cli/pull/14
```

```bash
ag pr close hust-open-atom-club/atomgit-cli 14
```

```output
Closed PR #14: https://atomgit.com/hust-open-atom-club/atomgit-cli/pull/14
```

如果你只需要在你的同一个仓库下，从一个开发分支（如 `test-head`）合入到主分支（如 `test-base`），可以直接省略 `owner:` 的前缀，这样系统会判断这是一个内部 PR：

```bash
ag pr create mywaaagh_admin/atomgit-cli --title 'Internal Repo PR Demo (Auto-generated by Showboat)' --body 'This is an internal PR creation test.' --base test-base --head test-head
```

```output
Created PR #2: https://atomgit.com/mywaaagh_admin/atomgit-cli/pull/2
```

```bash
ag pr close mywaaagh_admin/atomgit-cli 2
```

```output
Closed PR #2: https://atomgit.com/mywaaagh_admin/atomgit-cli/pull/2
```
